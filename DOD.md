# Definition of Done

Closure criteria for `project-commander` itself. The `dod` subcommand
reads this file and reports progress; tick `[x]` items as you confirm
them, leave the rest to be auto-evaluated against the repo state.

## Mechanical

- [ ] Working tree clean
- [ ] Pushed to origin
- [ ] On main branch
- [ ] Verify passes
- [ ] All plan phases complete

## Conduct

- [ ] No orphan threads
- [ ] No plan-drift
- [ ] Substantive prompts

## Manual

- [ ] User has reviewed the latest detail card
- [ ] Release notes updated for any user-facing change
